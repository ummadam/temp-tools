# Temp Tools

Temp Tools — веб-приложение интернет-магазина, разработанное на Laravel.

Проект предназначен для просмотра товаров, поиска, управления корзиной и оформления заказов.

## Технологии

- PHP
- Laravel 6
- MySQL
- Blade
- JavaScript
- Vue.js 2
- Bootstrap / SCSS
- Laravel Mix
- Voyager Admin Panel
- Composer
- npm

## Функциональность

- Каталог товаров
- Просмотр информации о товаре
- Поиск товаров
- Корзина покупок
- Изменение количества товаров в корзине
- Применение купонов
- Оформление заказов
- Регистрация и авторизация пользователей
- Личный кабинет
- История заказов
- Административная панель Voyager

## Структура проекта

- `app` — модели, контроллеры и логика приложения.
- `bootstrap` — загрузка приложения.
- `config` — конфигурационные файлы.
- `database` — миграции и сидеры.
- `public` — публичные файлы.
- `resources` — Blade-шаблоны, стили и JavaScript.
- `routes` — маршруты приложения.
- `storage` — кеш, логи и файлы приложения.
- `tests` — тесты.

## Установка

1. Клонировать репозиторий:

```bash
git clone https://github.com/ummadam/temp-tools.git
cd temp-tools
```

2. Установить зависимости PHP:

```bash
composer install
```

3. Создать файл `.env` с настройками приложения и базы данных.

4. Сгенерировать ключ приложения:

```bash
php artisan key:generate
```

5. Настроить базу данных MySQL.

6. Установить зависимости frontend:

```bash
npm install
npm run dev
```

7. Запустить приложение:

```bash
php artisan serve
```

Приложение будет доступно по адресу:

http://localhost:8000

Административная панель:

http://localhost:8000/admin

## Примечание

Проект основан на Laravel Ecommerce Example и адаптирован для интернет-магазина Temp Tools.
